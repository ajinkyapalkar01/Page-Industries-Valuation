# Page-Industries-Valuation
Financial Modelling, DCF Valuation &amp; Equity Research – Page Industries

## Project Overview
Investment Banking Capstone Project completed as part of the Boston Institute of Analytics programme.

## Project Scope
- Historical Financial Analysis (FY17–FY26)
- Three-Statement Financial Modelling
- Revenue and Expense Forecasting (FY27–FY31)
- Financial Ratio Analysis
- Discounted Cash Flow (DCF) Valuation
- Weighted Average Cost of Capital (WACC)
- Sensitivity Analysis
- Comparable Company Analysis (CCA)
- Investment Valuation Assessment

## Valuation Methodologies
- Discounted Cash Flow – FCFF
- Comparable Company Analysis – P/E Multiple

## Tools Used
- Microsoft Excel
- Financial Modelling
- DCF Valuation
- Financial Statement Analysis

## Project Files
1. Excel – Financial Model and Valuation Workbook
2. PowerPoint – Investment Banking Capstone Presentation

## Financial Data
Historical financial analysis uses standalone figures.
Forecasts and valuation outputs represent analyst calculations
and are not company guidance.

## Disclaimer
Academic project prepared for educational purposes.
Not investment advice.
